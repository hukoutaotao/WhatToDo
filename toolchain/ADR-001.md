# ADR-001 — Python for the local development prototype

Status: selected and spike-verified engineering choice, not a release/deployment freeze. This decision implements M2-16.a under D-080 and does not choose the user's eventual delivery channel.

Use Python 3.13.5 with the [Windows x64 wheel lock](../requirements-toolchain.lock), Psycopg 3.3.6 binary driver and project-local PostgreSQL 18.6 (EDB archive build 18.6-5). The exact packages, download URL/size and locally observed archive digest are in the [manifest](manifest.json). The archive comes from the Windows ZIP route linked by the [PostgreSQL download page](https://www.postgresql.org/download/windows/) and [EDB binary page](https://www.enterprisedb.com/download-postgresql-binaries). Its recorded digest is a reproducibility pin, not a publisher signature or a claim of the newest release.

## Bounded comparison

| Concern | Python evidence | TypeScript alternative |
| --- | --- | --- |
| Existing implementation | Reuses 13 tested offline slices, exact fractions/Decimals, dataclasses and provider-independent protocols. | Would require porting these modules and preserving the same contract/scenario evidence. No application port or schema library was installed for this comparison. |
| Time precision | Measured one-microsecond datetime difference remains 1 microsecond; existing tests preserve explicit offsets, DST folds and Beijing day rollover. | [Native probe](typescript-probe.ts) on Node v24.21.0 formats Beijing rollover correctly; native Date drops the one-microsecond difference. A different exact-time representation can address this. |
| Exact quantity | Fraction(1,3) remains 1/3; integers 9007199254740992 and 9007199254740993 remain distinct. | Native Number comparison collapses those values; BigInt distinguishes them. A rational/Decimal representation would be required for the existing contracts. |
| Schema/fake ports | Current JSON Schema checker and all fake-port regressions execute on the selected pinned environment. | A complete TypeScript checker/driver/port integration spike was not run. This is not evidence that TypeScript cannot satisfy the requirements. |
| Database | Actual native migration, constraint, transaction rollback and receipt reconciliation evidence is retained below. | No TypeScript PostgreSQL transaction spike was run. |

The choice follows measured reuse and exact-quantity compatibility. TypeScript remains replaceable behind the same contracts if a later interface requires it. The native Node probe uses type stripping and does not run a compiler/type check; that distinction follows the [Node documentation](https://nodejs.org/docs/latest-v24.x/api/typescript.html). Psycopg's binary package supplies client libraries; the observed bundled libpq is 180004, distinct from the server's 18.6 version. See the [driver installation reference](https://www.psycopg.org/psycopg3/docs/basic/install.html).

## Reproduce

Prerequisites: Windows x64, the pinned Python 3.13.5 interpreter and access to the fixed HTTPS package/archive sources for a first bootstrap. From the repository root:

```powershell
python tools/bootstrap_toolchain.py --verify
```

This creates `.venv` if absent, installs hash-locked wheels with a project-local cache, validates/extracts only PostgreSQL bin/lib/share and runs the checks. It preserves an existing environment/archive/extraction; a mismatch fails with a diagnostic instead of replacing files. It never installs a Windows service, edits global PATH, registers an account or uses existing database credentials.

Each native verification creates a new UUID directory under `.local-state/toolchain`, initializes synthetic data, listens only on 127.0.0.1, verifies the connected server's data-directory identity, applies all five drafts and inserts each migration's ID/hash in that same transaction. It stops its own server in `finally`. Logs/report/data are retained for diagnosis in ignored directories; no automatic recursive deletion occurs. The fixture-only trust authentication is confined to that temporary synthetic cluster and does not define application authentication.

To test a new environment while preserving `.venv`:

```powershell
python tools/bootstrap_toolchain.py --verify --venv-root D:\WhatToDo\.dev-tools\environments\my-fresh-spike
```

This option is constrained to `.dev-tools/environments`. A different OS/Python ABI needs a separately resolved hash lock. These commands verify the local prototype, not an arbitrary clean machine's global setup or a hosted application.

The report distinguishes the 248 Python regression methods, foundation SQL probes and six transaction/reconciliation checks. Actual checks include paired receipt/audit commit, explicit rollback of state/audit/receipt, rejection of an orphan deferred audit, duplicate command identity, stale epoch CAS and reading the originally committed receipt. These are native database spike observations, not a completed trusted command handler, production migration runner, full StateStore implementation or a universal exactly-once guarantee.

The first attempt exposed a Windows inherited-pipe wait when `pg_ctl` spawned its long-lived child. File-backed startup output fixed it; the exact failed test instance was stopped before rerunning. The native probes passed after that correction. Operational crash/restore/concurrency stress, runtime grants, full codecs, user-facing transport, n8n workflows and deployment remain separate tasks. No course profile, real Task/Calendar state or user availability was activated.
