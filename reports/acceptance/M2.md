- [Python/PostgreSQL ADR](../../toolchain/ADR-001.md), pinned dependencies and [native spike evidence](M2-16a.json) establish actual isolated execution of five draft migrations, 49 tables, 124 foreign keys, foundation probes and transaction checks. That archived report retains its original 248-method checkpoint; it is not relabeled as the later regression run.
- The current full regression run passes 283 methods. Existing 236 schema shape cases and 11 semantic scenarios are distinct from the five new cross-contract workflows. The semantic catalog explicitly retains 22 unmapped decision IDs; it does not certify the complete release.

## Generic gap to resolve next

The current [task-core schema](../../formats/input/task-core.schema.json) explicitly describes itself as an incomplete Task. Its independent effort/time/source contracts do not yet form a reusable whole-Task snapshot with consistent identity/revision, release/deadline and session/fragmentability/provenance fields. The cross-contract workflows check a bounded subset of that composition; they do not supply the missing aggregate contract to later repositories.

[M2-01.b](../../plan/tasks/M2_CONTRACTS.md#m2-01b) is recorded before implementation to fill this generic gap using accepted semantics and synthetic facts. New schema/codec ownership and its registry/design references must be tested before this audit can freeze the generic baseline. No new user information is required for that task.

## Separate later gates

Real profile/preset activation still requires the corresponding reviewed M1/M1B instances. Provider scopes, personal capacity, real channel/caller selection, service credentials, actual solver and production operation remain future evidence. These do not prevent the generic aggregate work. The application must implement trusted command resolution, transactional current-state checks, durable repositories and authorized audit/receipt publication before accepting real Task mutations; the current fakes cannot certify that path.

Next audit step: verify the complete generic Task aggregate and exact pinned input/output/path ownership, then assess whether the **offline/generic** M2 baseline can enter the M3 persistence foundation. Do not equate a local native spike or one finished child with that gate.
