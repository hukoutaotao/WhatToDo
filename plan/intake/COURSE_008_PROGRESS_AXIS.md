## 2. 分家族进度与遗漏

- 教学、预习、笔记、作业独立记录；本次实际事实在单独采集文件。作业/预习完成不能填补笔记遗漏；笔记 OPTIONAL 未完成不阻止既有作业 COMPLETE。
- 已知无遗漏前缀才能表达连续完成。当前三次笔记都未完成，不能由于教学、预习或作业到第 3 次而将它们标完成或漏掉积压。
- 已完成预习不失效；以后未完成且目标课已开始的预习，按 D-073 先通知后记录 EXPIRED，保留 INCOMPLETE 历史而不算补做积压。通知待办不得显示已失效。笔记周内窗口结束不自动失效。
- 合成例：教学到第 5 次，笔记第 1、2、4、5 次完成，第 3 次未完成；连续前缀只到 2，第 3 次仍是 OPTIONAL 待补。这不是用户实际状态。

## 3. 边界

三次未完成笔记可供后续已接受的遗漏检测机制使用，但本轮不因此自动生成补课/复习/Goal 或替用户决定重要性；具体生成映射/目标初始化仍属后续阶段。日期、完成/提交证据、计时、剩余预测和 Task 实例为动态数据；稳定轴不包含它们。
