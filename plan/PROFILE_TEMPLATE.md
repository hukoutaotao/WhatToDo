## 1. 引导采集顺序

用户用自然语言回答；AI 填写字段、标注来源、列出未知。不要求一次回答全部问题，不重复询问已有确定答案。用户明确暂缓的考试、大作业或其他长期计划标记为 DEFERRED，并记录范围及来源；本轮不追问，不推断不存在，也不因此阻止已授权的每周工作采集。

| 轮次 | 需要了解的内容 | 引导问题 |
| --- | --- | --- |
| 工作流程 | 任务家族、实际做法、要求与衔接 | 这门课平时产生哪些课外工作？怎样布置和衔接？哪些必须完成，哪些自己安排？ |
| 工作量与估时 | 每份/课次/周的范围；粗估或实测；区间 | 你估计每项花多久？这个时间覆盖一份作业、一次课还是一周？没有计时可以先粗估或留未知。 |
| 工作方式与难度 | 分段、最低有效会话、整段要求；思考/重复/新知各 1–5 | 能否分开做？至少连续多久有效？三项难度分别怎样？ |
| 时间与例外 | 布置/截止、正常窗口、软/硬顺序、失效条件 | 通常什么时候做和交？来不及时顺序能否调整？错过时间后补做还是失效？ |
| 进度单位 | 课次/章节/实验/主题及覆盖关系 | 你希望按什么单位记录进度？一项工作会覆盖多个单位吗？ |
| 当前状态（单独记录） | 已教单位、具体未完成/完成/失效；当前剩余量 | 现在进行到哪里？哪些工作做了、没做或正在做？实际日期只在当前用途需要且来源缺失时补问。 |

上课时间优先从已接入并已映射的日历获取。尚未接入时，星期/钟点可记录为稳定模式；具体下一次课日期仅在当前排程或条件判断需要时采集。缺少具体日期不阻止完成流程模板。日历事件不证明已上课、作业完成或课程进度推进。

活动使用同一身份、来源、估时与工作方式信息；按实际情况改问固定占用/灵活工作、频率、准备和出行缓冲，不强迫活动填写课程进度轴。

## 2. 每份档案的记录骨架

- 身份：稳定 ID、名称、种类/领域、正式学期（未知可留空）、格式版本与修订。
- 来源与审核：逐字段来源、用户陈述/接受默认/工程元数据的区别；审核所覆盖的范围与修订。新结构示例保持 DRAFT，不自动继承原自然语言档案的整份审核。
- 课程背景：用户报告的教学体验、学习感受、考试题源线索；注明是转述而非已核实事实，不擅自换算分数。
- 工作家族：做什么、数量范围、初始估时区间及是否计时、三维难度、分段与连续要求、义务性质、定性重要性、时间约束。
- 进度轴：单位含义、稳定标识、BEFORE/AT/AFTER、包含两端的范围或多个明确单位；不知道总数时不填学期总数。
- 工作关系：正常顺序、软/硬性质、允许的例外；区分材料来源、执行顺序与自动生成授权。
- 安排起点与适用范围：明确从哪个单位开始、哪些历史单位不建任务；不适用不等于未完成、完成或失效，不能因首次导入旧日历而追溯补建。
- 正式引用：TaskType/规则 ID 与确切版本，未建立时列为未知；自然语言家族不冒充已注册模板。
- 未知与扩展：缺失字段、受影响用途、后续负责阶段；命名空间扩展不覆盖核心含义。

当前状态另存：教学位置、任务实例及完成/失效、实际日历发生、投入时间、剩余估计、通知证据和具体考试范围。当前仅用来源化采集文档保存，未来进入 PostgreSQL；不得移进稳定默认。

## 3. 从第一门课提炼出的约束

1. 20–30/60/40 分钟是未实测的典型工作估计，必须带工作量范围；不能变成每个具体任务的用户剩余量或训练样本。
2. 三维难度分别记录。定性“笔记最重要”不能补写数值重要性；课程没有主要重要性标量。
3. 总量、最低有效会话和要求一次完成分别记录。预习 30 分钟不能安排成两段 15 分钟；作业 40 分钟不是永远固定的上限。
4. REQUIRED/OPTIONAL/EXPIRING 是义务性质；INCOMPLETE/COMPLETE 是完成事实；EXPIRED 是处置。预习在目标实际课开始时未完成可按 D-073 先通知后记录失效。笔记周日窗口结束不自动失效。
5. 笔记先于作业是软顺序，截止紧迫允许先做作业再补笔记；不能因为笔记未完成就撤销已完成作业。
6. 轴不强制为课次；换成章节或实验通过配置描述。已完成后面单位不能填补前面的遗漏；跨单位工作只计一次工作量。
7. 教材来源、关系引用和默认值本身不授权生成任务；自动生成映射仍由 M1B/M2 定义与审核。

## 4. 兼容性与验收边界

保留 [0.1 原合成示例](examples/STABLE_PROFILE_V0_1.synthetic.json)及第一门课的原审核档案不变。0.2 是附加采集字段与轴表达的 SPEC 提案，旧字段含义不变：0.1 → 0.2 显式修改格式版本即可，新增可选字段不补默认值；保留 ID、来源、未知声明和扩展原值。0.2 → 0.1 若存在新增字段，必须明确拒绝或保存独立完整附加数据并报告，不能静默删除。

来源化结构示例包含第一门课稳定事实和原文材料路径，DRAFT、USER_PROFILE、无当前进度。JSON 读写往返应保留每个字段和非关键扩展；原审核证据只支持其注明的源档案/字段范围，不证明新的机器表示通过整份审核或可激活。另用内存合成配置核对章节/实验轴、缺失上下文和扩展阻断；不创建用户的新课程或运行时校验器。

M1-05 的验收是格式、兼容说明与例子的一致性；M1B 仍负责 TaskType/规则，M2 仍负责冻结机器 schema、注册引用与可执行校验。物理实验由用户另一个对话负责，本轮不读取或修改其档案；本对话下一门为 `course-003` 马克思主义基本原理。
